# Soul Forge visual assets

The weapon sprites in `weapons/` are from [Pixel art Sword & Scimitar Set](https://opengameart.org/content/pixel-art-sword-scimitar-set) by mujtaba-io on OpenGameArt.org.

- License: CC0 1.0 Public Domain Dedication
- Attribution: not required by the author, but this source notice is retained for project transparency.
- Files used: `sword4_1.png`, `sword-3_0.png`, `sword2_8.png`, `sword_39.png`
- Local mapping: `ember-sword.png`, `gale-sword.png`, `tide-sword.png`, `legacy-sword.png`

## Fonts

- `Noto Sans KR`: Google Fonts, SIL Open Font License 1.1. Loaded from Google Fonts in `forge.css`.
- `IBM Plex Mono`: IBM, SIL Open Font License 1.1. Loaded from Google Fonts in `forge.css`.

## Audio

The short hit, forge, and summon cues are generated at runtime with the browser Web Audio API. No third-party audio file is bundled.
